# GhostLink
> One link. Infinite Experiences. Adaptive link experience for modern web.
GhostLink is a link generator that generates personalized content for each visitor all in one link.

## Why GhostLink?
GhostLink uses adaptive rules to deliver personalized content to each visitor. Whether you're a job seeker, entrepreneur, or content creator, GhostLink helps you create a single link that adapts to your audience, showcasing the most relevant information to each visitor.

## Features
- **Adaptive Content**: Create one link that delivers different content based on the visitor's context, such as their device, location, or referral source.
- **Easy Customization**: Use an intuitive interface to set up your adaptive rules and customize the content for each visitor.
- **Analytics**: Track how your link is performing with detailed analytics on visitor interactions and engagement.
- **Shareable**: Share your GhostLink across social media, email, or any platform with a single URL.

## Getting Started
1. ```zsh
    git clone https://github.com/praneet1503/GhostLink.git
   ```
2. go to env example and create a .env file with the required environment variables.
3. ```zsh
    npm install
   ```
4. ```zsh
    npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
